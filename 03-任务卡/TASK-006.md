## 背景与目标

把已完成能力整合为可在联网 Mac/Windows PC 使用的本地交易辅助系统，提供按钮、运行时每小时刷新和简洁 HTML 图表。

**依赖与输入资料：**

- REQ-001 R11 的按钮、运行期间 1 小时周期、电脑查看、Mac/Windows、免费行情及 Codex 会员要求。
- A1 第 3.7–3.8 节、W6 及已确认 D3。

## 范围

**要做：**

- 提供本地运行入口及浏览器操作页，把配置、数据、计算、Codex 推导、计划和复盘接为完整流程。
- 实现手动触发按钮，以及系统运行期间每 1 小时刷新；显示周期状态、当前进度与最近成功/失败轮次。
- 让手动与周期触发采用一致流程，处理触发重叠、服务停止、休眠和断网后的恢复状态。
- 首页突出市场判断及时间、少量候选及主要理由、计划提醒和关键图表；完整列表、指标、反证与缺口按需展开。
- 提供知识确认、计划确认/直接记录、执行回填及复盘的对应操作，保留每步业务确认含义。
- 提供某轮结果的自包含 HTML 查看能力；运行界面与静态报告的能力范围清楚，源数据时间和分析时间分别呈现。
- 支持本地档案持久使用及 Mac/Windows 之间的文件迁移，整体资料包含知识、计划、执行和关联历史；首期不自动同步。
- 完成目标运行环境的启动说明、必要前置和实际自检记录；根目录薄启动入口的具体文件名在完整设计中确定。

**不做（硬边界）：**

- 不增加自动交易、付费行情、未经同意的模型 API、多机云端同步或手机专用应用。
- 不在服务退出后承诺后台刷新，不把断网期间的旧数据标为新数据。
- 不重写前序指标/归档/计划规则，不把静态 HTML 示意页当成可运行的系统。

## 验收标准

以下是可观察的交付标准，供后续独立测试与验收据此开展；当前均未执行或验证。

- [ ] **AC01（正常）**：用户可以在目标电脑启动本地系统，通过页面按钮触发一次完整取数、计算、Codex 解读和结果呈现；运行前置有明确说明。
- [ ] **AC02（正常）**：系统运行期间具备每 1 小时刷新能力，手动/周期状态可辨认，触发重叠不会相互覆盖原始轮次与确认记录。
- [ ] **AC03（展示）**：首页具有市场摘要、候选、计划提醒和图表，主要信息清晰；完整指标与依据可展开，数据/分析时间和缺口可见。
- [ ] **AC04（业务操作）**：知识确认、计划确认/手工记录、执行回填和复盘可通过界面完成，引用与人工确认结果保留。
- [ ] **AC05（边界）**：退出服务、休眠、休市或断网时，状态与实际可用性一致；恢复后取得最新可用数据，不集中补跑大量旧分析。
- [ ] **AC06（异常）**：数据源或 Codex 失败时保留最近成功结果和本轮错误，旧结果不能伪装成当前轮；无效配置、存储问题可定位。
- [ ] **AC07（迁移与环境）**：本地资料可在声明支持的 Mac/Windows 环境迁移并维持引用；平台实际自检及未验证项如实记录，最终双平台覆盖由小步正式验证，不凭声明视为通过。
- [ ] **AC08（交付边界）**：运行界面实际调用前序能力；导出的自包含 HTML 无外部 CDN 依赖，凭据不进入页面/提交，系统不具备下单权限。
