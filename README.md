# trade

本地运行的交易辅助系统，用“逻辑、技术、模式、计划”组织观察、分析与复盘。支持 A 股与美股，实际买卖由用户操作。

## 主要功能

- A 股：同花顺行业、宽基及自选范围，市场盘面、量价与候选方向。
- 美股：三大指数、七个美国行业、纽约金、市场广度及宏观与盈利观察。
- 对应美股指数的境内 ETF 固定配对、K 线及有明确基准的净值偏离。
- Codex 解读与可配置的 DeepSeek 后备；档案、计划、执行回填及复盘保留版本。
- 本地 HTML 页面、日周图表、可选均线、资料导入导出与可恢复回收站。
- 手动更新；定时能力默认关闭，需自行开启。

## 快速启动

环境：Python 3.8+、Node 22.x，可联网；Node用于全市场历史文件解析。使用 Codex 时需本机已有可用的 Codex CLI。DeepSeek 通过页面独立配置，不需要把密钥写进代码。

克隆本仓库后，在仓库根目录运行：

```sh
python3 src/trade.py setup
python3 src/trade.py serve
```

也可使用入口文件：

- macOS：双击 `启动交易助手.command`。
- Windows：双击 `启动交易助手.cmd`，或运行 `py -3 src/trade.py serve`。

页面地址为 <http://127.0.0.1:8765>。关闭服务时在启动终端按 `Ctrl+C`。

盈利解析所需依赖会安装到本项目 `.local/python-packages/`。数据、运行配置、缓存和凭据保存在 `.local/`，不会上传到 GitHub；新设备需自行配置 AI 接入。
