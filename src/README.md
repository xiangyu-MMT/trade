# P03 trade · 本地交易辅助系统

本系统用于取数、技术计算、Codex 解读、计划确认、执行回填与复盘。实际交易由你操作，程序没有下单接口。

## 启动

需要 Python 3.8+；程序使用 Python 标准库，无需安装第三方 Python 依赖。AI 使用当前可用的 Codex CLI 配置，不限定认证类别；也可在页面配置 DeepSeek API。若以 npm 安装 Codex，按工作区约束使用 Node 22.x。

- Mac：双击项目根的 `启动交易助手.command`。
- Windows：双击 `启动交易助手.cmd`，需要可用的 Python 与 Codex。Windows 尚未在本机实测，应由小步在实际设备完成正式验证。
- 默认地址：`http://127.0.0.1:8765`。Mac 自动用 Google Chrome 打开；Windows 使用系统默认浏览器，建议 Chrome 或 Edge。
- 保持启动窗口运行，周期能力才有效。退出时在启动窗口按 Ctrl+C。
- 后台终端运行的是本地网页服务。页面显示“待命”且定时关闭时，不持续取数或调用AI；服务保留是为了响应按钮。Ctrl+C退出后，已有静态报告仍可阅读，交互操作需重新启动。
- 电脑休眠期间不取数、不调用 AI。唤醒后周期任务只补一次到期刷新，不集中补跑；正在进行的网络/AI调用可能恢复或报超时，查看本轮状态后再触发即可。连续取数时请保持电脑清醒。

从工作区根手动启动：

```sh
python3 projects/P03-trade/src/trade.py serve
```

更换端口或数据目录：

```sh
python3 projects/P03-trade/src/trade.py --home /path/to/local-data serve --port 8766
```

一个数据目录同时只允许一个运行实例。应用只监听本机，不修改局域网、路由或防火墙。

## 日常使用

1. 在“配置”查看固定行业、八项指数与个股。行业定义固定为同花顺。配置文件在项目 `.local/config.json`。
2. 每次启动默认手动模式。点击“更新分析”，或主动开启运行时每小时刷新。界面显示取数、计算和 AI 阶段；已有任务运行时不会重复覆盖。
3. 在“概览/候选”看数据日期、结论、反证、图表与缺口。历史轮次可以回看。
4. 从候选生成计划草稿，或在“计划”直接记录。没有指定实际 ETF/个股时保存为观察计划。
5. 补充个人仓位与风险规则，再确认具体计划版本。档案中的规则可标记为“仓位/风险规则”，确认后供计划引用。
6. 自己完成买卖后回填事实，再生成复盘。系统不会读取券商成交或自动交易。
7. 复盘或分析的归纳建议可保存为档案草稿，只有明确确认后进入可用知识集合。

新修订不会覆盖旧版确认内容；待确认草稿不会替换原已确认规则。旧报告、计划和回填保留原引用。

## 配置入口

`.local/config.json` 是运行配置，页面“配置”也可以编辑、校验和保存。程序更新不会覆盖已经存在的用户配置。

| 字段 | 用途 |
|---|---|
| fixed_industries | 同花顺行业名称或代码；默认煤炭开采加工、银行、电力、工业金属 |
| top_n | 在同花顺行业目录中按当日累计成交额选取的数量，默认 10 |
| indices / stocks | 宽基与个股列表，每项包含 asset_id 和 name；个股如 sh600000、sz000001 |
| execution_mappings | 你明确选择的实际 ETF/个股映射；默认空，程序不会代选 |
| etf_observations | 份额观察篮子，独立于交易映射；不代表同指数全部基金的合计 |
| watch_indices | 全市场额外观察指数；中证金融、微盘股需明确具体口径后配置 |
| auto_refresh / refresh_seconds | 本次服务的周期开关与秒数，每次启动默认关闭；周期默认3600秒 |
| ai | 提供方、Codex命令/模型/超时，以及DeepSeek启用、地址/模型/超时；API Key使用独立入口 |
| max_import_bytes | 资料导入上限，默认 100MB |

同花顺行业 ID 形如 `ths:881155`。中证 2000 使用本地 ID `csi932000` 并从中证指数官方序列取数。不要将其他提供方的同名行业代码填入同花顺行业配置。

配置中不要放密码、Cookie 或 API 密钥。行情适配器使用无需专门账号的免费来源；Codex沿用现有可用配置。DeepSeek密钥通过页面独立入口或DEEPSEEK_API_KEY环境提供。

Codex沿用当前认证、提供方与模型配置，使用本次分析所需的只读、结构化输出和中等推理参数，默认最长300秒，不改写个人配置。DeepSeek启用并配置密钥后可接替失败调用；也可选为优先提供方。成功、超时和启动失败均保留诊断，用户取消时停止整轮，不继续后备调用。

## 数据与时间

- 同花顺：行业定义、行业指数日线与当日累计数据；行业净流入来自其公开表格。
- 全市场：优先东方财富，异常时以新浪 A 股目录与腾讯带时间戳报价补充；统计剔除北交所、B 股及名称含 ST 的证券。
- 中证指数公司：中证 2000 官方日频序列。
- 上交所/深交所：ETF 份额或当前规模文件；没有源日期时不编造跨日变化。
- 融资余额：公开日频汇总；宏观观察使用配置声明的市场代理、FRED或美联储发布。

免费来源可能有字段缺口、格式变化或访问限制。应用先尝试真实替代源，仍无法获取时明确标注；不把缺失值填成行情，也不把不同公司的行业分类互相替代。

程序保存源时间与获取时间。内置已核实的 2026 年上交所休市日历；例如 2026-09-25 为中秋节休市，9 月 24 日是最近交易日。其他年份日历未核实时会明确提示，需更新日历资料。来源见 [上交所2026年休市通知](https://www.sse.com.cn/disclosure/announcement/general/c/c_20251222_10802507.shtml)。

同花顺行业原指数口径可能包含与股票统计范围不同的成份；只有成份与报价全部校核完成，才使用完整剔除后的行业成交额，否则保留原公布口径说明。股池封板率也保留提供方的新股排除说明。

## 本地保存与迁移

默认运行目录 `.local/` 已被 Git 忽略，包含配置、SQLite 数据库、数据缓存和 AI 输入输出。资料保存在本机；首期不自动云同步。

页面可导出完整 JSON 资料包，包含知识/计划版本、回填、复盘、分析轮次和原始 AI 数据记录。导入会核对版本、引用和内容冲突；已有相同版本的不同内容不会被覆盖。迁移不包含 Codex 登录信息，新电脑需要单独登录。

每轮也可导出自包含 HTML 结果。静态 HTML 可以离线阅读；触发、确认与回填需要本地服务运行。

## 实现自检与维护入口

以下为调用入口，正式测试由小步独立负责：

```sh
python3 src/trade.py --home /path/to/isolated-data collect --output snapshot.json
python3 src/trade.py --home /path/to/isolated-data compute --input snapshot.json --output facts.json
python3 src/trade.py --home /path/to/isolated-data run --snapshot snapshot.json
python3 src/trade.py --home /path/to/isolated-data status
python3 src/trade.py --home /path/to/isolated-data report --run-id RUN_ID --output report.html
```

`run --snapshot` 使用真实已保存快照并保留原数据日期，不会宣称重新取数。`--no-ai` 仅供明确需要程序事实时使用，结果会标注 AI 未调用。

自检使用工作区 `.scratch/` 的独立目录，正式使用目录不混入隔离自检的计划和说明记录。当前实现交付状态、提交及限制见各 TASK 完成说明；正式测试和独立验收结果不由 Codex 代填。

## I2 · 量价、模型配置与回收站

- 在“配置 → AI接入与后备”编辑提供方、地址、模型与超时，API Key只存本机 `.local/credentials.json`，页面不回显；密钥不进入Git、报告或迁移。新设备需重新配置。未配置时不调用DeepSeek。
- 每次服务启动关闭定时。用户开启后按小时运行；浏览器重载保持本次状态，资料导入不会开启定时。
- 首页前三使用AI对逻辑、模式与量价的综合排序；无AI时明确标为程序量价参考。候选先宽基，再固定行业与动态前三；前十行业仍全部分析。
- 日线量价只比较完整交易日，提供1/5/20日价格变化、前5/20日量比和涨跌日均量关系。K线、淡色MA5/20/60/120与量柱同屏，周线辅助。
- 全市场严格沪深非ST成交额由真实收盘快照逐日积累；交易所沪深A股（含ST）历史作为单独参考，两类序列不拼接。深圳历史日期来自日期查询参数，文件未单列日期。
- 计划和执行可移入回收站并恢复，保留原对象版本与关联；删除计划不级联删除执行/复盘。已删除执行不进入新复盘，旧复盘提示引用状态。
- 迁移格式为archive_version=2，包含回收站状态，兼容导入旧版1；生命周期有冲突时拒绝覆盖。
- 当前自检覆盖Mac、真实Codex与免费行情来源。未配置用户DeepSeek密钥，因此真实DeepSeek调用尚未验证；Windows和正式测试仍待小步进行。

## I3 · 市场观察曲线与输入范围

本节更新I2中市场成交额的展示和口径安排：采用沪深A股成交额统一显示，正常页面只写“市场成交额”。盘中用对应时点累计值，收盘日优先交易所公布数，历史不与旧过滤口径拼接。

- 程序读取基础行业成交额排行榜以筛选前十；只取选中行业详情和历史，不再抓90行业成份，AI也只接收选中行业。全市場盘面保留汇总统计。
- 市场概览直接显示融资余额60日曲线与较上一交易日变化；数据未发布到当日时显示实际源日期。
- 沪深300(IF)和中证1000(IM)基差使用同日全系列在市合约收盘，按持仓量加权计算期货价减指数价，单位点；正升水、负贴水。来源是中金所日CSV与同日指数历史。
- 涨停与跌停历史按来源可得范围绘图，无数据日期不补0，曲线在缺口处断开。提供方股池范围保留于详情。
- 已移除“有效量价候选”概览卡片；融资余额日变化在首页直接可见。
- 本项目允许按需安装联网依赖并记录版本；当前这些适配器使用现有运行环境直连公开来源。

## I4 · 每张小图独立切换

日线/周线按钮位于每个行业、宽基和首页候选卡内部，各图独立切换，不取数、不调用AI。当前只使用5日、20日两条均线，计算、排序和图例同步调整；旧四线配置读取时迁移到两条。周线图取周K结束日的5日/20日日均线值，仍是日均线。旧知识版本与历史报告保留，新轮次引用更新后的技术知识。

## I5 · 均线显示选择

按后续明确要求，**图表显示**可在每张小图下方勾选MA5/20/60/120日，首次仅显示MA20，也可全部隐藏。每个标的的选择保存在当前浏览器，刷新后保持；周线图和详情沿用该图选择。静态报告默认显示MA20。此显示选项不修改指标配置、计算、排序、知识或AI解读，也不触发分析；分析参数继续按原设置执行。
