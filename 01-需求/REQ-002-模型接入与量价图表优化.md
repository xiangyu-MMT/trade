## 2. 本轮需求整理

### RQ01 · Codex 可用即可，DeepSeek 可配置降级

- 取消应用对“必须是 ChatGPT 会员登录”的硬性限制。使用当前设备实际可用的 Codex 调用方式，不因认证类别不是 ChatGPT 就在应用层拒绝。
- Codex 无法使用或本轮解读失败时，有 DeepSeek API 后备路径；提供清楚的配置入口，可设置服务地址、模型、API Key 的本机配置及是否启用后备。密钥只在本机配置，不要求在对话发送，不进入 Git、报告或迁移资料包。
- Codex 的已有有效服务配置应能用于调用；应用调用规则不应意外屏蔽用户已配置的认证、提供方或模型。具体兼容方式由后续设计核实。
- 降级覆盖市场/候选分析、计划拟定和复盘。每次结果记录实际使用的提供方、模型、是否降级及原因，不把 DeepSeek 输出标成 Codex。
- DeepSeek 未配置、被用户关闭或同样失败时，保留程序计算、图表与历史，明确本轮缺少 AI 解读。用户主动取消整轮时停止，不把取消当成失败而继续后备调用。
- 免费要求继续针对行情；本轮明确允许用户自行配置 DeepSeek API，不再把旧版“仅会员路径、不切换 API”作为本轮约束。

### RQ02 · 定时默认关闭，主动开启才运行

- 默认只允许用户主动触发分析。运行时每小时刷新的能力保留，必须由用户明确打开。
- **本 R1 的具体建议**：每次服务启动默认关闭；用户本次开启后按小时运行，刷新浏览器页面不改变本次服务的开关状态；关闭后不再产生下一次周期触发。迁移资料或程序更新不自动开启。
- 该“每次启动”的具体化属于 Codex 建议，随本 R1 一起审阅，不记为翔宇已逐字确认。
- 当前本机应用已按本轮原话关闭周期设置，API 返回 `auto_refresh=false`、`next_refresh=null`；这项现有运行设置调整已完成。程序默认值及启动行为尚待后续实现修订。

### RQ03 · 候选重点展示综合最强前三

- 首页“候选重点”从本轮限定候选集合中选综合最强的三个：综合熟悉逻辑、市场模式匹配、价格结构和量能证据；其中量价关系是核心依据。
- 不是按输入顺序、成交额大小或简单状态标签截取三个，也不将原始价格、均线绝对值或不同单位的成交量直接跨对象比较。
- 给出简短的相对强弱理由和关键反证；相对较强与已经形成交易机会分别表达。整体不适合交易时，前三仍可以是观察/等待，不能为凑数强行变成可交易推荐。
- 数据足够的候选少于三个时说明覆盖不足；不编造得分、胜率或不存在的依据。具体可复算比较方法与 AI 的判断职责在后续技术设计中明确。

### RQ04 · 计划与执行记录可删除、可恢复

- 翔宇已选择“移入回收站，可恢复”。计划及执行回填提供删除入口，删除后退出正常列表，并可在回收站查看、恢复。
- 删除计划时，关联执行和复盘保留，能够看出原计划处于删除状态；不进行未明确选择的级联删除。
- 删除执行记录后，新复盘不再把该记录当作有效执行事实；已经生成的历史复盘保持当时引用与来源，并能看到原记录已删除。
- 恢复保留原对象、版本、确认状态和关联，不恢复成新的重复对象。回收站状态随本地保存和资料迁移保留。
- 首期不加入永久清空能力。本条授权开发删除能力，不授权 Codex 删除现有用户记录或文件。

### RQ05 · 宽基优先，行业前十全分析、前三展示

- “候选与依据”首先展示已有八项宽基/指数；每个列表项自带 K 线、均线和成交量，不要求先点开文字详情才能看到走势。
- 同花顺行业成交金额前十仍全部参与取数与分析；常规页面只展示这十个中按综合强度选出的前三。该前三与首页从全部候选中选前三是两个范围。
- 固定煤炭、银行、电力、工业金属与用户配置个股仍按既有范围分析；“动态前十仅展示前三”不减少固定关注集合。对象重复时合并展示并注明入选来源。
- 完整十个的分析结果留在轮次记录，供追溯，不以减少展示数量为由只分析三个。页面顺序不改变实际分析范围。

### RQ06 · 量价关系成为技术与盘面的重点

- 首要观察是 K 线价格结构、MA5/20/60/120 与量能的相互关系。用真实开高低收绘制蜡烛图；均线用较淡、仍可区分的线条；成交量柱与 K 线时间对齐。
- 日线为主、周线辅助。K 线、均线、成交量在列表中一眼可见；不把均线绝对值表、MACD、CCI、OBV 数值放在主视觉。辅助指标仍可用于分析和按需查看。
- **全市场量能**：围绕全市场成交额及量能变化，结合涨跌家数、价格方向、行业扩散/集中，解释市场是在如何运动。不能用候选集合的量能代替全市场。
- **板块量能**：对同花顺行业观察量能与价格结构、强弱持续性及行业之间的相对关系，特别解释高成交额行业的量价反应。
- **宽基量能**：逐项观察宽基价格与量能是否配合，比较不同规模/风格的强弱与变化；指数自身、对应股票汇总和ETF代理的口径必须分清。
- 分析重点包括上涨/下跌过程中量能增加或减少、突破/回撤时量能是否配合等现象；结论应结合熟悉逻辑与模式，不把单一形态直接等同于买卖指令。
- 量能变化需要可比的历史或同时间段依据。盘中累计值不直接与前一完整交易日总量比较后宣布缩量；只有当天数据、历史缺失或口径不同，就明确无法判断。成交金额、成交股数、份额和资金净流入分别标明。
- 不编造放量倍数、因果结论或统一阈值；具体历史窗口、程序统计和视觉表达在已确认需求基础上设计。

### RQ07 · 市场概览有理解，展示简洁

- 将翔宇原话“市场概念”理解为现有“市场概览”页面；本轮不是新增概念板块分类。
- 市场概览包含：**市场点评、盘面结构分析、市场模式识别**。点评回答当前市场如何运动、重点观察什么；结构解释全市场量价、广度与强弱分布；模式给出识别结果、依据与冲突。
- 以图表、短结论和必要标记承载信息。市场、板块和宽基量能图配简短解释；避免大段文字重复描述数字。
- 重点候选突出“为什么较强 / 量价是否配合 / 还欠什么条件”。资料来源、完整指标、反证与缺口可展开，关键数据缺失与时间仍清楚可见。
- 运行页面与静态报告遵循相同重点；静态报告不冒充可执行界面。
