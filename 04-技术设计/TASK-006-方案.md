## 方案与选择依据

| 关键选择 | 理由及处理 |
|---|---|
| ThreadingHTTPServer + 原生 HTML/CSS/JS + SVG | 标准库启动，系统字体和内联/本地样式，图表不依赖 CDN；本地服务承担按钮和敏感配置访问。 |
| 只绑定 127.0.0.1 | 默认端口 8765，可通过命令参数改；不开放局域网，不修改路由/防火墙。API 检查 Host/Origin，写请求需本进程随机令牌。 |
| 后台 Runner + 轮次状态 | 界面请求立即返回任务 ID；轮询状态。手动与每小时任务共用互斥锁，成功/失败后安排下轮，休眠恢复只触发最新一轮。 |
| 本地可迁移，不自动同步 | 导出版本化 JSON 包；导入先校验结构、引用、冲突和体积，再事务合并；不上传到云。 |

## 接口、数据与错误约定

1. GET /api/state、/api/config、/api/runs、/api/runs/{id}、/api/knowledge、/api/plans、/api/executions、/api/jobs/{id} 返回版本化 JSON；大快照在服务端保留，界面只取图表与所需摘要。

2. POST /api/run；POST /api/knowledge、/{id}/revise、/{id}/confirm；POST /api/plans/draft、/api/plans/manual、/{id}/revise、/{id}/confirm；POST /api/executions、/api/reviews；PUT /api/config；GET /api/export；POST /api/import。所有写请求验证本地 Origin/令牌及载荷。

3. 错误信封为 error:{code,message,details}，400 输入无效、404 不存在、409 忙/版本冲突、503 来源或模型不可用、500 内部错误；不向页面暴露凭据或堆栈。

4. 启动 python3 src/trade.py --home <目录> serve --port 8765；默认 .local/。Mac .command 和 Windows .cmd 只定位目录并调用 Python 主入口，业务代码全部在 src/。

5. 首页只展示市场摘要、候选重点、计划提醒和两类关键图表；详情可展开。运行/数据/AI生成时间分开显示；等待或缺口与完整结论外观有区别。

6. 导出报告为自包含 HTML，CSS/SVG 内联，数据文字转义；生成后本轮用 Chrome 打开。运行页面通过本地服务获取数据，不将登录凭据嵌入 HTML。

7. 迁移仅包含数据和配置，不包含 Codex 认证资料。文件大小上限在配置中明示；引用冲突整次拒绝，现有确认记录不覆盖。

跨任务共用约定：不可变 run_id 与 object_id@revision；所有源时间与生成时间分开；知识/计划确认由明确用户动作完成；数据缺口可追溯。后续若协议实质变化，在受影响方案和实现记录中说明，不无声更换。
