这是职责建议。模式定义、阈值和取舍由你的交易体系决定；系统归纳出的新内容经你确认后再纳入。

适合你的运行节奏：程序约每 5 分钟更新数据和指标；你每天两次看盘时生成重点解读，必要时手动刷新 AI。具体查看时间随后再定。

为什么这样选，以及 Skill 放在哪里

纯规则便于复算，但每种模式都要定义条件；纯 AI 便于解释新情境，却难以保证每次计算和措辞一致。组合方案把数值依据留在程序里，让 AI 对照依据形成解释。

配置保存参数与明确条件；归档保存你的总结、案例和定义；Skill 可以说明“先读什么、如何调用计算工具、按什么格式解释”。它们服务同一套流程。OpenAI：插件、Skill 与 MCP

首期可以用已有 AI 助手按需解读程序输出；如果以后要自动生成报告，再选择模型调用方式并核算费用。免费行情与 AI 使用成本分别核算。

“胜率”需要明确样本、规则、统计窗口与成本后计算。AI 的语气或置信度不能直接充当历史胜率。复盘应能回到当时数据、计划和所用定义。

先核验同花顺免费接口能覆盖多少

你已经使用同花顺，首个候选可以是 iFinD 数据接口。官方文档提供 Python / HTTP 行情调用，公开权限页列出免费实时行情额度为每月 300 万条。需要对应 iFinD 账号及接口权限；当前普通软件使用情况尚不能证明你已开通。接口手册 · 免费额度

免费方案尚未实测覆盖全部需求。候选行情、板块资金、封板率、ETF 份额、海外数据要分别核对。数据获取时间与源数据时间都应保留，页面直接显示过期或缺失项。

MCP、小步和 Codex 怎么接入；还有哪些渠道

MCP 负责把工具和数据暴露给 AI，数据的内容、时效与权限仍由提供方决定。Codex 支持本地及远程 MCP；也可以通过程序调用正式 HTTP / Python 接口。Codex MCP 官方说明

WorkBuddy 官方提供 MCP 连接机制。如果小步已有可用行情连接器，可以评估复用；持续采集建议交由定时程序，助手读取同一份带时间戳的数据。你所说的具体连接器、授权与覆盖范围尚未验证。WorkBuddy 连接器文档

通达信官方还提供行情 Python 接口及本地 HTTP 调用方式；迅投 XtData 可订阅行情。这些是备用接入路径，账号、费用、运行环境与字段都要核对。通达信部分接口依赖 DLL，当前 Mac 是否可用需单独确认。通达信 tqserver · 迅投 XtData

本次插件目录搜索未找到同花顺、通达信或 iFinD 的匹配项；当前会话没有已连接的上述专业行情工具。核实的是公开文档，尚未登录你的账号或取得实际行情。

可以程序交易，开通要经过券商

券商支持的 QMT 等渠道已经能够用程序报单、撤单、查询委托和成交。技术上可行，实际能开通什么取决于你的券商、账户和所交易品种。迅投交易接口

需要哪些条件

  1. 证券账户及对应品种的交易资格。
  2. 券商允许使用的程序接口，并完成其开通、协议及适当性要求。
  3. 按适用规则完成程序化交易报告，再开始相关交易。

门槛高不高

能够接入不等于能够稳定实盘。接口开通后，还要正确处理成交、撤单和断线等状态。

未确定券商前，我不能给出“需要多少万元”的可靠数字。资产门槛、适当性、功能及费用应以开户券商当前要求为准。

证监会规定自 2024-10-08 实施，要求先报告后交易；上交所实施细则自 2025-07-07 实施，官方页面标为现行有效。证监会规定说明 · 上交所实施细则

规则的范围包含程序自动生成或下达交易指令。若以后系统生成可执行的交易指令，不能只根据“最后由人点击”判断是否需要报告，应由开户券商确认具体使用方式。
